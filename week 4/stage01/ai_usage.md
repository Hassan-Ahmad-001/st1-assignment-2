# AI Usage Documentation

## AI tool used

Microsoft Copilot, as required by the lab instructions.

## Purpose of AI use

AI was used as a Python tutor and to generate an alternative beginner-friendly appointment-booking function.

## Tutor prompt

> Act as a Python tutor.
> I am learning introductory software technology.
> Here is a small appointment-booking function.
> 1. Explain what the code does.
> 2. Identify three limitations.
> 3. Suggest improvements.
> 4. Do not rewrite the whole application.
> 5. Ask me two questions to test my understanding.

## Alternative-generation instruction

I asked AI to create a simple beginner-friendly Python function that stores patient name, practitioner name and appointment time. I explicitly prohibited a database and GUI.

## Verification

The AI output was reviewed and tested rather than accepted automatically. I checked normal input, blank patient names, duplicate practitioner/time appointments, and unusual `None` values.
